==============================================

1. Unzip ScrapperPro-for-laptops.zip
2. Double-click Install-ScrapperPro.bat
3. In Chrome:
   - Enable Developer mode
   - Load unpacked
   - Select the folder that opened

Settings:
  API URL  = https://scrapper-api-0i33.onrender.com
  Site key = walden     (for WALDN Members / Fluent UI table)
             quotes     (for quotes.toscrape.com/scroll)

On the Members page: refresh the tab, open the popup, Save, Start.
Keep the Members tab focused while scraping.
